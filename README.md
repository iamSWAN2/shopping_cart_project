# 파이썬 장바구니 프로젝트

터미널에서 상품을 조회하고 장바구니를 관리하는 파이썬 연습 프로젝트입니다. 상품의 가격과 재고, 장바구니 합계와 배송비를 다룹니다.

## 실행 방법

Python 3가 설치되어 있어야 합니다. `main.py`가 있는 폴더에서 다음 명령을 실행하세요.

```bash
python3 main.py
```

메뉴 번호를 입력해 기능을 선택하고, `q`를 입력하면 종료합니다.

## 메뉴

| 입력 | 기능 |
| --- | --- |
| 1 | 상품 번호, 이름, 가격, 재고 확인 |
| 2 | 상품을 장바구니에 담기 |
| 3 | 장바구니에서 상품 빼기 |
| 4 | 장바구니와 상품 합계, 배송비, 결제금액 확인 |
| 5 | 쿠폰 (미구현) |
| 6 | 결제 (미구현) |
| q | 프로그램 종료 |

장바구니가 비어 있거나 상품 합계가 30,000원 이상이면 배송비는 0원입니다. 그 외에는 3,000원입니다.

## 함수와 메서드

### 상품: `Product`

| 메서드 | 기능 |
| --- | --- |
| `__init__(name, number, price, inventory)` | 이름, 번호, 가격, 재고로 상품을 만들고 `PRODUCTS` 목록에 추가합니다. |
| `get_price()` | 상품 가격을 반환합니다. |
| `set_price(price)` | 0 이상의 가격을 저장합니다. |
| `get_inventory()` | 현재 재고를 반환합니다. |
| `set_inventory(inventory)` | 0 이상의 재고를 저장합니다. |

가격과 재고는 `__price`, `__inventory`에 저장하고 메서드를 통해 읽거나 변경합니다.

### 장바구니: `Cart`

| 메서드 | 기능 |
| --- | --- |
| `__init__()` | 상품 번호를 키, 수량을 값으로 저장할 빈 딕셔너리를 만듭니다. |
| `show_in_cart()` | 담긴 상품의 이름, 수량, 상품별 금액과 전체 합계, 배송비, 결제금액을 출력합니다. |
| `add_product()` | 상품 번호와 수량을 입력받아 장바구니에 담고 재고를 줄입니다. |
| `remove_product()` | 상품 번호와 수량을 입력받아 장바구니에서 빼고 재고를 늘립니다. 남은 수량이 0이면 해당 키를 삭제합니다. |

### 그 밖의 함수

| 함수 | 기능 |
| --- | --- |
| `show_title()` | 메뉴 제목과 선택지를 출력합니다. |
| `find_product(num)` | 상품 번호로 `PRODUCTS`에서 상품 객체를 찾아 반환합니다. 찾지 못하면 `None`을 반환합니다. |
| `show_products()` | 전체 상품의 번호, 이름, 가격, 재고를 출력합니다. |
| `handle_menu(num)` | 입력한 메뉴 번호에 맞는 함수나 메서드를 실행합니다. |
| `main()` | 메뉴 입력을 반복해서 받고 선택한 기능을 실행합니다. `q`를 입력하면 종료합니다. |

## 현재 구현 상태

- 쿠폰과 결제 기능은 아직 구현되지 않았습니다.
- 상품과 장바구니 정보는 실행 중에만 유지되며, 프로그램을 다시 실행하면 초기화됩니다.
- 상품 번호와 수량에 정수가 아닌 값을 입력하면 오류가 발생할 수 있습니다.
- 수량이 0 이하이거나 장바구니에 없는 상품을 빼려는 경우, 안내 메시지 출력 후에도 처리가 계속되는 부분은 개선이 필요합니다.
